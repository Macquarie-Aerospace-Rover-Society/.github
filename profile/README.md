# Macquarie Aerospace Rover Society

Welcome to the official GitHub organisation for the **Macquarie Aerospace Rover Society**.

We are a student-led team focused on designing, building, and testing rover technologies through collaborative engineering projects.

## What you'll find here

- Rover software and autonomy work
- Embedded systems and electronics tooling
- Mechanical design support assets
- Team documentation and workflows

## Our approach

We value practical engineering, clear documentation, and continuous improvement through testing and iteration.

## Get involved

If you're interested in contributing, explore our repositories and open an issue or pull request to start a conversation.
